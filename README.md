# АИС «Кредитный аналитик»

## Описание проекта
Автоматизированная информационная система для учёта и анализа выдачи кредитов юридическим лицам.

## Предметная область
Выдача банком кредитов юридическим лицам (вариант №19).

## Основные функции
- Регистрация клиентов (юридических лиц)
- Оформление кредитных заявок
- Классификация кредитных операций по видам кредитования
- Формирование отчётов по динамике выдачи кредитов
- Выявление и анализ просроченной задолженности
